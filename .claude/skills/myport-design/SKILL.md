# ออกแบบหน้าแอป Myport

ผู้ใช้ไม่ใช่โปรแกรมเมอร์ อธิบายเป็นภาษาไทย ทีละขั้น และ **เสนอแบบให้เห็นภาพก่อนแก้จริงเสมอ**

## ข้อเท็จจริงของแอป (ห้ามทำพัง)
- แอปไฟล์เดียว `index.html` (HTML+CSS+JS ในไฟล์เดียว ไม่มี build) เปิดผ่าน GitHub Pages จาก branch `main` ติดตั้งเป็นแอปบนมือถือ (PWA)
- ข้อมูลพอร์ตอยู่ใน `localStorage` ของเครื่องผู้ใช้เท่านั้น (`myPortfolio.v1`) — **repo เป็นสาธารณะ ห้ามใส่ข้อมูลพอร์ตจริงในโค้ด/ภาพที่ commit**
- `market.json` บอทเขียนให้ทุกเช้า (ข้อมูลตลาดสาธารณะ) อย่าแก้มือ: `today` (ความเครียด, แนวโน้ม W/D), `risk` (vol/corr, เหตุการณ์จริง, vol_scale), `assets` (กติกามวลชน→CDC), `stocks` (ผลคัดหุ้น)
- ราคาสด BTC/ทอง (PAXG) จาก Binance WebSocket, ค่าเงินจาก open.er-api.com
- แท็บล่าง: 🧭 วันนี้ · 📊 พอร์ต · 🎯 แผน/DCA · 💰 เงินเดือน (`showTab`, `renderToday`, `render`, `renderPlan`, `renderSalary`)
- **แก้ทุกครั้งต้องเพิ่ม `APP_VERSION`** (รูปแบบ `YYYY.MM.DD-n`) ไม่งั้นมือถือยังแสดงหน้าเก่า
- โหมดซ่อนยอดเงิน: ตัวเลขเงินต้องมี class `money` (body.hide จะเบลอ)
- ข้อความทุกหน้า: เป็น "สถานะ/ตัวเลขประกอบ" ไม่ใช่คำแนะนำซื้อขาย; ห้ามแสดงผลทายทิศทางราคา (งานวิจัยไม่ผ่าน)

## ระบบดีไซน์ปัจจุบัน (ใช้ token เดิม อย่าใส่สีตรงๆ)
- **2 ธีมตามมือถืออัตโนมัติ**: มืดเป็นค่าเริ่มต้นใน `:root`, สว่างใน `@media (prefers-color-scheme: light)` — เพิ่มสีใหม่ต้องใส่ทั้งสองที่; ห้ามใส่ hex ตรงในสไตล์ (ใช้ token หรือ `color-mix(in srgb, var(--x) 14%, transparent)`)
- token: `--bg --card --card2 --line --text --muted --up --down --accent --on-accent` (ตัวอักษรบนปุ่ม accent) `--top1` (แถบสีหัวหน้า) `--shadow`
- แถบสีด้านบน + หัวขาว แสดงเมื่อ `body[data-tab=today|port|plan]` (หน้าเหล่านี้ต้องเริ่มด้วยการ์ด hero)
- ความหมาย: `--up` เขียว, `--down` แดง, `--accent` (มืด = ทอง, สว่าง = น้ำเงิน) ปุ่มหลัก/ลิงก์
- สีสินทรัพย์: `--c-gold --c-btc --c-stock --c-gpf --c-hi --c-normal --c-jar` (ใช้สีเดียวกันทุกหน้า)
- ฟอนต์ IBM Plex Sans Thai; ความกว้างสูงสุด 520px; ขอบมน 12–20px
- หน้า "วันนี้" = สรุป (hero+กราฟ `S.hist`, ปุ่มลัด `.acts`, ตลาด, วงแหวนเทียบแผน `ringSVG`, กติกา, รายการเครื่องมือ) รายละเอียดเปิดเป็นแผ่น `openPanel(title, html)` ผ่าน `data-do` → `todayAction()`; เพิ่มรายละเอียดใหม่ = เพิ่มฟังก์ชัน `xxxDetail(v)` + กรณีใน `todayAction`
- `S.hist` = มูลค่าพอร์ตรายวัน (จดใน `recordHist` เก็บ 400 วัน ในเครื่องเท่านั้น)
- คอมโพเนนต์: `.hero` (ตัวเลขใหญ่บนสุด), `.card`, `.list > .line(.full)`, `.row`, `.meta`, `.small`, `.tag(.ok/.bad)`, `.note(.ok/.bad)`, `.alloc` (แถบสัดส่วน), `.legend`, `.bar2` (แถบเทียบเป้า), `.inrow` (ช่องกรอก+ปุ่ม), sheet แก้ไข (`openSheet`)

## ขั้นตอนเมื่อผู้ใช้ส่งแอปตัวอย่าง
1. **อ่านภาพ** แล้วสรุปเป็นข้อๆ ว่าชอบได้เพราะอะไร แยก 5 ด้าน:
   - โครงหน้า (อะไรอยู่บนสุด, ลำดับความสำคัญ, จำนวนข้อมูลต่อหน้าจอ)
   - การแสดงตัวเลข (ตัวใหญ่/เล็ก, สีขึ้นลง, กราฟเล็ก sparkline, วงแหวน, แถบ)
   - การนำทาง (แท็บล่าง, การ์ดแตะเข้าไปดูรายละเอียด, ปัด, พับ/ขยาย)
   - สไตล์ (สี โทน ระยะห่าง ขอบมน เงา ไอคอน ฟอนต์)
   - สิ่งที่ **ไม่ควรลอก** (โลโก้/ชื่อ/ภาพของแอปนั้น — ยืมแนวคิด ไม่ลอกหน้าตาทั้งชุด)
2. **จับคู่กับ Myport**: ข้อมูลแต่ละอย่างในแอปเรามี (พอร์ต, แผน, ความเสี่ยง, ตลาดวันนี้) จะวางตรงไหนตามแนวตัวอย่าง ระบุสิ่งที่ทำไม่ได้ (เช่น ไม่มีข้อมูลนั้น, ไม่มีเซิร์ฟเวอร์)
3. **เสนอ 2–3 แบบ** สั้นๆ พร้อมข้อดี/ข้อเสีย แนะนำ 1 แบบ แล้ว **รอผู้ใช้เลือก**
4. **ทำภาพจำลอง** ด้วยข้อมูลสมมติ: แก้สำเนาใน scratchpad ไม่แตะ repo แล้วรัน `node .claude/skills/myport-design/preview.js <โฟลเดอร์สำเนา> <ไฟล์ภาพ> [แท็บ] [light|dark] [selector ที่จะแตะ]` ส่งภาพให้ผู้ใช้ดู (เทียบก่อน/หลัง ทั้งสองธีม)
5. ผู้ใช้โอเค → แก้ `index.html` จริง, เพิ่ม `APP_VERSION`, ทดสอบทุกแท็บด้วย preview.js (ต้องไม่มี `ERR`), commit ขึ้น `main`, บอกผู้ใช้ว่าเปิดแอปแล้วจะอัปเดตเอง

## หลักอ่านง่าย (เช็กก่อนส่งทุกครั้ง)
- บรรทัดแรกของทุกหน้าตอบคำถามหลักของหน้านั้นได้ทันที (วันนี้ = ตลาดเป็นไง, พอร์ต = มีเท่าไร, แผน = ห่างแผนแค่ไหน)
- 1 การ์ด = 1 เรื่อง; รายละเอียดรองพับไว้หรือย้ายไปหน้าย่อย
- ตัวเลขสำคัญใหญ่ ตัวเลขประกอบเล็กและสี muted; หน่วยชัด (฿, %, ต่อปี)
- สีเขียว/แดงใช้กับ "ขึ้น/ลง" เท่านั้น ไม่ใช้กับ "ดี/ไม่ดี" ของการตัดสินใจ (เช่น ห่างแผนใช้สีกลาง)
- ศัพท์เทคนิคต้องมีคำแปลสั้นๆ (W = ภาพใหญ่รายสัปดาห์, ±1 SD ≈ 68%)
- มือถือจอ 390px ไม่มีเลื่อนแนวนอน ปุ่มแตะได้ ≥ 40px ตัวอักษรเล็กสุด 12px
- ใช้ได้ทั้งตอนยังไม่มีข้อมูล (ยังไม่กรอกยอด/ยังไม่มี market.json/ราคายังไม่มา)
